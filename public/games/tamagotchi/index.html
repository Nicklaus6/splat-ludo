📖 饲养手册

🐣 孵蛋

  • 一切从一颗蛋开始:点点屏幕 帮它暖蛋,不点的话大约 5 小时也会自己孵化。
  • 孵出来先起个名字,然后就是你的崽了。

🕹️ 操作方式(和 1997 年的原机一样)

  • 屏幕上下各有一排功能图标:A 键 移动光标、B 键 执行、C 键 取消。
  • 偷懒的话,直接点图标也行。点屏幕 = 摸摸它(它会开心一点点)。
  • 图标从左到右:吃饭 / 零食 / 玩耍 / 打扫(上排)、吃药 / 灯 / 状态(下排)。
  • 右下角 ❗ 亮起 = 它在呼唤你,快去看看是饿了、病了还是拉了。

🍙 日常照顾

  • 四项指标(藏在状态图标里):饱食、心情、精力、卫生,都会随时间下降。
  • 吃饭管饱;零食涨心情但不顶饿;玩「猜方向」小游戏最涨心情,不过费体力。
  • 它随时可能拉 💩,不打扫卫生会掉得很快,还容易生病。
  • 精力耗尽它会自己睡着;也可以用灯提前哄睡,睡饱自然醒。

🤒 生病与死亡(是真的会死!)

  • 太脏或太饿容易生病,生病要赶紧喂药,拖 36 小时 不治会死。
  • 饿到 0 或心情到 0 的状态累计 48 小时,它也会离开你。
  • 死了只能重新孵一颗蛋——所以,好好待它。

✨ 成长

  • 成长阶段:蛋 → 宝宝(12小时)→ 幼年(2天)→ 少年(5天)→ 成年。
  • 关掉网页它也在长大:时间照常流逝,回来时该饿的饿、该拉的拉。云端存档,换设备接着养。

🎨 换壳

  • 右上角「换壳」可以给机身换配色,换壳不影响里面的崽,选择会存进云端。
